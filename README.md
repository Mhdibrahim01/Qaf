## ✨ المميزات الرئيسية • Key Features

### 1. 🗂️ بطاقات استذكار بتكرار متباعد علمي (SM-2 Spaced Repetition)
- تطبيق خوارزمية **SuperMemo SM-2** لتحديد فترات المراجعة الدقيقة (Again / Hard / Good / Easy) حسب استيعابك.
- تقليب بطاقات سلس بـ 60/120 إطار في الثانية، مع دعم النطق الصوتي الفوري (US/UK Phonetics).
- شريط تحكم مرن يدعم جميع أحجام الهواتف وشاشاتها.

### 2. 📖 قراءة متدرجة تفاعلية (CEFR A1–C1 Graded Reading)
- نصوص ومقالات باللغة الإنجليزية مصنفة حسب مستويات الإطار الأوروبي المشترك (CEFR).
- **الضغط الفوري على أي كلمة أثناء القراءة:** استعراض معناها وسياقها الصوتي واللغوي فوراً دون مغادرة النص.
- استفسار الذكاء الاصطناعي (Gemini AI Context Explanation) لشرح الكلمة في سياق الجملة بدقة معجمية موجزة وخالية من الحشو.
- أسئلة فهم مقروء (Comprehension Questions) تفاعلية بنهاية كل نص.

### 3. 📚 قاموس أوفلاين مدمج وفوري (10,317 Offline Word Profiles)
- أكثر من **10,317 ملف لغوي تفصيلي** مخزن محلياً على الهاتف:
  - النطق الصوتي الدقيق بالأبجدية الصوتية الدولية (US/UK IPA) وتقطيع المقاطع (Syllables).
  - المعنى الدقيق بالعربية والإنجليزية مع أمثلة سياقية مترجمة.
  - المتلازمات اللفظية (Collocations) والاشتقاقات والتأصيل اللغوي (Etymology).

### 4. 🎓 قواعد تفاعلية واختبارات إعادة ترتيب الجمل (Interactive Grammar)
- دروس قواعد مبسطة للمستويات من A1 إلى C1 مع فلاتر حسب المستوى والموضوع.
- تدريبات تفاعلية مع نظام ترتيب الجمل (Sentence Reordering Quiz) واختبارات الاختيار من متعدد مع تصحيح ذكي فوري.

## 🏗️ البنية البرمجية والتقنيات • Architecture & Tech Stack

- **لغة البرمجة:** 100% Kotlin حديثة ونظيفة.
- **واجهة المستخدم:** Jetpack Compose + Material Design 3 مع دعم كامل للوضع المظلم (Dark Mode) وRTL/LTR ثنائي اللغة.
- **قاعدة البيانات المحلية:** Android Jetpack Room (SQLite) مع دعم الفهرسة والبحث النصي السريع (FTS).
- **إدارة القوائم الكبيرة:** Jetpack Paging 3 للتحميل التدريجي الفوري وتوفير استهلاك الذاكرة.
- **محرك الذكاء الاصطناعي:** Google Gemini AI API للشرح اللغوي السياقي وتوليد الأسئلة.
- **الصوتيات:** محرك تشغيل صوتي مدمج يدعم النطق الصوتي البريطاني والأمريكي مع معالجة التخزين المؤقت (Audio Cache).

## 🛠️ كيفية بناء التطبيق وتشغيله (Build & Run)

### المتطلبات الأساسية (Prerequisites):
- تثبيت [JDK 17](https://adoptium.net/) أو أحدث.
- [Android Studio Ladybug / Meerkat](https://developer.android.com/studio) أو عبر سطر الأوامر باستخدام Gradle.

### 1. استنساخ المستودع (Clone Repository):
```bash
git clone https://github.com/Mhdibrahim01/Qaf.git
cd Qaf
```

### 2. إعداد مفتاح الذكاء الاصطناعي (Gemini API Key - اختياري):
أنشئ ملف `.env` في المجلد الرئيسي وضع به مفتاح Gemini المجاني:
```properties
GEMINI_API_KEY="your_free_gemini_api_key_here"
```
*(ملاحظة: يمكنك أيضاً إدخال المفتاح مباشرة من داخل إعدادات التطبيق على الهاتف في أي وقت).*

### 3. بناء ملف APK للتثبيت المباشر على الهاتف:
```powershell
.\gradlew.bat assembleRelease
```
*الملف الناتج ستجده في:* `app/build/outputs/apk/release/app-release.apk`

### 4. بناء حزمة المتجر (App Bundle - AAB):
```powershell
.\gradlew.bat bundleRelease
```
*الملف الناتج ستجده في:* `app/build/outputs/bundle/release/app-release.aab`
